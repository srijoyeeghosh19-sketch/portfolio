# Portfolio Website

A fast, accessible, no-build portfolio for a beginner frontend developer. Plain HTML, CSS and JavaScript, so every line is yours to read and change.

## Run it
Open `index.html` in your browser. For auto-reload, use the VS Code "Live Server" extension.

## Make it yours
1. **index.html**: replace "Your Name", the intro, the three projects, skills, about text and contact links. Search for `your-username` and `example.com`.
2. **style.css**: colors and fonts live in the `:root` block at the top.
3. **assets/**: put a screenshot of each project here and add it with an `<img alt="...">` (always write alt text).

## Publish for free (GitHub Pages)
```bash
git remote add origin https://github.com/YOUR-USERNAME/portfolio.git
git push -u origin main
```
Then on GitHub: Settings > Pages > Deploy from branch > `main` / root. Your site appears at `https://YOUR-USERNAME.github.io/portfolio/`.

## Before you share it
- Real projects with live links beat many unfinished ones. Three is plenty.
- Describe what you learned in each project, not only what you used.
- Test with the keyboard (Tab key) and on your phone.
- Check it in Lighthouse (Chrome DevTools) and aim for green scores.
